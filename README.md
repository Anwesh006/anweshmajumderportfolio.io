## ✨ Features

- **Interactive Canvas Background:** Dynamic interactive DotField particle physics.
- **Modern Typography:** Instrument Serif, Plus Jakarta Sans, and JetBrains Mono.
- **Smooth Animations:** Powered by GSAP & CSS transforms.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports.
- **Sections:** About, Skills & Technologies, Featured Projects, Experience & Education, Contact.

## 🚀 Running Locally

Clone the repository and serve the files with any static server:

```bash
# Clone the repository
git clone https://github.com/Anwesh006/anweshmajumderportfolio.io.git
cd anweshmajumderportfolio.io

# Start a local server (Python)
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
